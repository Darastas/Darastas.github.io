FocusFeed 0.1.6

RSS 账户同步、AI 朗读、官方公告订阅与版本检查。

这次更新让你在 FocusFeed 中连接现有阅读服务，也能听文章和电子书。

订阅、阅读与收听，在同一个界面完成。

本次更新

  • RSS 账户：完整接入 FreshRSS、Miniflux、Tiny Tiny RSS、Google Reader 兼容 API 和 Fever API。支持订阅、分组、文章与已读 / 收藏同步；Fever 的订阅管理仍在服务网页完成。
  • 离线状态同步：本机已读与收藏变更进入持久队列，联网后自动补传。同步失败可以重试，未上传的操作不会被远端旧状态覆盖。
  • 服务入口：账户页按云服务、自托管与 API 分组，提供 Feedly、Folo、Feedbin、BazQux、The Old Reader 的官网与接入说明。
  • AI 朗读：在 AI 设置中独立选择语音接入、模型、音色与速度，并可试听。支持 OpenAI 兼容语音接口及 Gemini AUDIO 输出。
  • 阅读与划词朗读：AI 栏可朗读当前文章或电子书章节，划词工具条可朗读选中文字；共享播放器支持暂停、继续、停止与进度显示。
  • 划词动画：工具条以 160ms 的 ease 曲线渐显，与软件常规弹窗一致；保留拖拽动效，并支持系统减少动态效果设置。
  • 检查更新：设置 → 关于的版本号右侧新增按钮，检查官方存储中的版本清单，提示最新版本、可用更新或检查失败，并提供公告与下载入口。
  • 官方公告：软件侧栏固定置顶官网公告源。公告提供全文 RSS，方便直接在阅读器内查看。
  • 官网：新增公告索引、独立文章与移动导航，调整标题、网格与间距。

使用说明

账户兼容性修正

  • 修复 Tiny Tiny RSS 文章正文为空的问题，并准确提示订阅失败。
  • 修复 Miniflux 的 Fever 接口订阅与分组读取，确保文章正常同步。
  • 已连接真实 FreshRSS、Miniflux 和 Tiny Tiny RSS 服务，验证文章分页、已读 / 收藏回传，以及断网后重新打开软件并补传操作。

在设置 → RSS 账户中添加阅读服务，按提示填入服务器地址与 API 凭据。账户切换器可以查看全部账户、本地订阅或单个账户。服务器分组请在阅读服务的网页中管理。

在设置 → AI 接入中添加语音服务，再分配独立的朗读模型。模型需要支持音频输出；普通文字模型不能用于朗读。使用你自己配置的服务，费用按服务方的规则计算。

下载

支持 Windows 与 Android。前往官网下载页面获取安装版、便携版或 Android 安装包。
