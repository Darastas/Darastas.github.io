FocusFeed 0.2.3：系统托盘、备份恢复与朗读进度

桌面端可收起到托盘继续同步和朗读；用单个文件备份配置与阅读数据；朗读支持点击、拖动跳转和原文浮窗。Windows、Android 与 Linux 同步提供 0.2.3，朗读界面另有 r12 小更新。

FocusFeed 0.2.3 加入系统托盘与单文件备份恢复，并改进 AI 朗读进度。 Windows、Android 和 Linux 均提供新版安装包。朗读界面也提供签名小更新，方便仍在使用旧版核心的用户获取改进。

桌面端收起到托盘

  • 进入设置 → 通用，可开启最小化或关闭窗口后收起到托盘，开关默认关闭。
  • 收起窗口后，应用继续运行，后台同步和正在播放的朗读可以继续。
  • 单击托盘图标恢复窗口；托盘菜单提供「显示」和「退出」。要完全结束应用，请选择「退出」。
  • 该功能用于 Windows 和支持系统托盘的 Linux 桌面。Linux 未能创建托盘图标时，不启用窗口收起，避免窗口无法找回。

用一份文件备份与恢复

进入设置 → 备份与恢复，导出一个专用的 .ffbackup 文件，方便重装或换设备时恢复。

  • 备份包含订阅、账号、AI 配置、个人许可、阅读记录、收藏、批注和外观设置；可以选择一并包含电子书文件。
  • 导入时先校验文件并准备恢复数据，当前阅读可以继续；重新启动应用后执行恢复，尚未重启时可以取消。
  • 恢复会替换当前本地配置与阅读数据。建议先导出当前设备的备份；恢复过程保留原数据副本，失败时还原。
  • Android 通过系统文件选择器保存和选择备份文件。新设备需先安装 0.2.3 或更新版本，再导入备份。

备份中包含账号凭据、API 密钥和许可信息，请妥善保管，不要公开分享。 未选择包含的电子书文件不会随备份迁移。

AI 朗读：跳到想听的位置

  • 进度采用细轨道和滑块，可直接点击或拖动跳转；聚焦进度条后，也可用方向键、Home 和 End 调整位置。
  • 悬停或调整进度时，浮窗显示该位置对应的原文片段，便于找到想继续听的内容。
  • 原文位置按语音时长估算，不提供逐字时间戳。
  • r12 界面将播放控件独立放在一行，修复窄阅读栏和 125% 缩放时进度条遮挡工具按钮的问题；顶部工具栏的原文浮窗向下展开。
  • 改善长文章跳段、暂停后跳转和继续后快速跳段的响应。

如何更新

托盘与备份恢复需要安装 0.2.3 整包。 请保留原有数据，安装对应平台新版；Android APK 延续此前签名，可直接覆盖安装。

安装后，进入设置 → 关于 → 界面小更新，主动检查并下载 0.2.3-ui.2（r12），获取最新朗读布局。也可下载签名界面包，使用「导入更新包」安装。

  • r12 兼容 0.2.0 至 0.2.x 核心；Android 0.2.0 请先更新 APK，修复旧版热更新模块。
  • 旧版核心安装 r12 后可以使用朗读改进；托盘与备份入口会提示先安装 0.2.3 整包。
  • 下载或导入后，下次启动生效。Windows 和 Linux 可「重启并应用」；Android 请结束应用后重新打开。
  • 尚未应用时可以取消；应用后可恢复上一界面。回退界面保留订阅、文章、收藏和许可，不会撤销已安装的原生功能。

验证范围

本次已完成三端安装包的本地构建、公开下载校验，以及 Windows 真实客户端的备份往返、重启恢复、朗读跳转与旧版在线界面更新、回退验证。

Android 本轮未进行实机验收，覆盖安装与系统文件选择器仍待设备验证；Linux 实际桌面的托盘操作、Windows 托盘右键退出尚未完成实测。
