FocusFeed 0.2.4：粘贴网页地址，自动查找订阅源

修复文章链接或网站首页被直接当作 Feed 解析而报错的问题，自动查找网站提供的 RSS、Atom 和 JSON Feed，改善订阅错误提示。Windows、Android 与 Linux 同步更新。

FocusFeed 0.2.4 改善订阅地址识别。 添加订阅时，除了直接填写 RSS、Atom 或 JSON Feed 地址，也可以粘贴网站首页或文章链接，应用会尝试查找该网站提供的订阅源。

修复网页地址订阅失败

此前，一些网站的文章链接会提示 Feed 解析失败: unable to parse feed: no root element。原因是该地址返回网页，而应用直接按订阅源解析。

  • 现在会查找网页中声明的订阅链接；文章页没有声明时，继续查找网站首页及常见订阅路径。
  • 支持相对订阅链接、网页基址与地址跳转，保留稳定的订阅入口，便于后续同步。
  • 例如太隐网站的文章链接可找到其订阅源 wangyurui.com/feed.xml。
  • 自动识别成功后，原订阅条目使用真实源地址，保留分组、解析模式、收藏和已读状态。
  • 改善重复源识别，处理粘贴地址末尾误带的常见中文标点。

文章链接会订阅该网站的更新。 该篇文章是否出现，取决于网站订阅源提供的文章范围；此功能不等同于保存单篇网页。

没找到订阅源时，说明原因

未发现可用源时，应用会提示检查网站是否提供 RSS、Atom 或 JSON Feed，并尝试填写实际订阅地址。

此功能需要网站提供可发现的订阅源，不会为任意网页生成 RSS。需要登录、验证码或受源站访问限制的网站，仍可能无法订阅。

如何更新

请安装 0.2.4 完整安装包。 本次修复位于应用核心，仅安装界面小更新无法获得。保留原有阅读数据，安装后可重新刷新此前失败的网页订阅，或重新添加地址。

  • Windows 0.2.4 安装版
  • Windows 0.2.4 便携版
  • Android 0.2.4 ARM64 APK
  • Linux 0.2.4 x86_64 DEB
  • Linux 0.2.4 x86_64 RPM

官网下载区提供 SHA-256 校验值与 Linux 终端安装命令。Linux 继续为 Beta，需要 glibc 2.34 或更新版本及 WebKitGTK 4.1。

验证范围

发布前完成本地回归、三端安装包构建及公开下载校验；Windows 真实客户端验证太隐文章链接的订阅发现、文章入库与后续刷新，Linux 验证隔离启动。Android 本轮未连接实机或模拟器，设备端覆盖安装和订阅操作仍待验证。
