FocusFeed 0.2.2：完整正文、视频卡片与播客播放

修复 4Gamers 全文不完整与部分 YouTube 卡片缺失，新增播客和音视频播放器、定时同步设置。Windows、Android 与 Linux 已提供 0.2.2，界面小更新同步发布。

FocusFeed 0.2.2 让正文更完整，也让音视频内容更好读、更好听。 本次修复 4Gamers 全文与部分 YouTube 卡片缺失，增加媒体播放器和定时同步设置。Windows、Android 与 Linux 安装包已更新；订阅、文章、笔记和许可继续保存在本机。

后续修订 0.2.2.1 增加可选启动预加载，并修复普通正文外链的打开方式。查看 0.2.2.1 公告可获取当前安装包和完整更新说明。

全文与 YouTube 卡片修复

  • 修复 4Gamers 部分文章只提取到标题、封面或开头内容的问题，恢复网页中的完整正文。
  • 修复部分文章正文完整、YouTube 卡片却被遗漏的问题，视频卡片保留在原来的段落位置。
  • 升级后，之前保存的 4Gamers 全文会在下次进入全文阅读时重新尝试抓取；原有阅读记录、收藏和批注保留。
  • YouTube 卡片由你点击后加载播放器，使用 YouTube 的隐私增强嵌入模式；点击前不请求视频或缩略图。

上述正文提取、视频保留与旧缓存修复需要安装 0.2.2。如果只安装界面小更新，旧核心遗漏的视频仍需要新版安装包才能恢复。

播客与音视频播放器

阅读页增加统一的媒体控件，支持 RSS / Atom 提供的音频和视频附件，适合播客等订阅源。

  • 播放、暂停和拖动进度。
  • 快退 15 秒、快进 30 秒。
  • 调整播放倍速与音量。
  • 视频全屏，以及通过外部播放器打开。
  • 全文解析后仍保留订阅源提供的音视频附件；切换文章时停止已移除的播放器。

播放器界面可通过小更新获得。RSS / Atom 媒体附件解析及全文后附件保留需要安装 0.2.2；旧版中已经存在的音视频内容也可使用新控件。

设置定时同步

进入设置 → 通用 → 定时同步，选择 15 分钟、30 分钟、1 小时，或自定义 1–10080 分钟，让订阅源按自己的节奏更新。

  • 定时同步在应用运行时生效；设备休眠或网络离线可能使同步延后，关闭应用后不会继续执行系统后台同步。
  • 0.2.2 可统一调整本地 RSS 与远程账户的同步间隔。FreshRSS、Miniflux 等服务仍按所属账户同步。
  • 旧核心使用界面小更新时，仅调整本地 RSS 的间隔；电子书和系统公告源不参与此设置。
  • 设置保存在本机，新加入的源会沿用已选择的间隔。

本次没有加入每月文章下载配额或同步时预先抓取所有全文的功能。

同时包含此前的文件夹小更新

  • 文件夹菜单提供「文件夹内文章解析」，可一次调整文件夹内订阅源的解析方式，包括全文解析。
  • 文件夹初始默认收起，按需展开查看订阅源。

如何更新

要获得本次完整修复，请保留原应用和数据，安装对应平台的 0.2.2。应用「检查更新」按平台提供安装包：Windows 提供 EXE，Android 提供 APK，Linux 提供 DEB / RPM。

  • Windows 0.2.2 安装版
  • Windows 0.2.2 便携版
  • Android 0.2.2 ARM64 APK
  • Linux 0.2.2 x86_64 DEB
  • Linux 0.2.2 x86_64 RPM

Android 可直接覆盖安装，签名与此前版本保持一致。Android 0.2.0 的热更新问题需要先通过新版 APK 修复。Linux 继续标为 Beta，需 WebKitGTK 4.1 与 glibc 2.34 或更新版本；官网下载区提供校验值和终端安装方式。

界面小更新与恢复

播放器、定时同步设置和文件夹界面可从设置 → 关于 → 界面小更新获得。本次界面版本为 0.2.2-ui.1，更新序号为 8，兼容 0.2.0、0.2.1 和 0.2.2 核心。也可下载签名界面包，通过「导入更新包」安装。

  • 更新包在本地验签后，下次启动生效。Windows 和 Linux 可「重启并应用」；Android 请结束应用后重新打开。
  • 尚未应用时可「取消待更新包」；应用后可「恢复上一界面」，再重新打开应用。
  • 界面回退保留订阅、文章、许可和已保存的同步间隔；需要改变间隔时，请在设置中重新选择。
  • 界面回退不会撤销 0.2.2 安装包中的原生修复。开发者可通过发布更高序号的旧界面资源撤回界面变更。

本次没有新增登录系统或云端阅读数据库。更新检查与下载不上传订阅、文章、授权码或 API 密钥；全文抓取与媒体播放按你的操作连接对应网站。
