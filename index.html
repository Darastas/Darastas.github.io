在终端安装。

复制这条命令，自动选择 DEB / RPM、校验 SHA-256 并安装 Linux 0.2.4 Beta。支持 Linux Mint、Ubuntu、Debian（apt）与 Fedora（dnf）。

curl -fsSL https://focusfeed-site.pages.dev/install.sh | sh

安装前请关闭 FocusFeed。脚本会处理旧 Beta 重装与误标版本降级；仅安装阶段需要 sudo。需要 curl、sha256sum 和可提供 WebKitGTK 4.1 的软件源。

查看手动安装命令

Linux Mint / Ubuntu / Debian

curl -fL --proto '=https' --proto-redir '=https' 'https://focusfeed-site.pages.dev/download/FocusFeed_0.2.4_amd64.deb?rev=cddf83eb8128504b08e9c9e8307f0460ab1a05f1b1ddef932ba477d0a8e6c247' -o 'FocusFeed_0.2.4_amd64.deb' &&
printf '%s  %s\n' 'cddf83eb8128504b08e9c9e8307f0460ab1a05f1b1ddef932ba477d0a8e6c247' 'FocusFeed_0.2.4_amd64.deb' | sha256sum -c - &&
sudo apt-get install --yes --allow-downgrades --reinstall './FocusFeed_0.2.4_amd64.deb'

Fedora（dnf）

curl -fL --proto '=https' --proto-redir '=https' 'https://focusfeed-site.pages.dev/download/FocusFeed-0.2.4-1.x86_64.rpm?rev=24f6c3ae3a5f8cd2df659fa0c44e9f26b8dc124d176af2f5a53527c5d9c4a3bb' -o 'FocusFeed-0.2.4-1.x86_64.rpm' &&
printf '%s  %s\n' '24f6c3ae3a5f8cd2df659fa0c44e9f26b8dc124d176af2f5a53527c5d9c4a3bb' 'FocusFeed-0.2.4-1.x86_64.rpm' | sha256sum -c - &&
sudo dnf install './FocusFeed-0.2.4-1.x86_64.rpm'

RPM 已安装同版时，将 install 改为 reinstall；误标的 0.17.0 需改为 downgrade。安装后从应用菜单启动，或以普通用户运行 rss-cross-app。

查看安装脚本 ↗

Windows 文件暂未进行代码签名，系统可能显示“未知发布者”；安装前可核对上方 SHA-256。Android 版需要 ARM64 设备，并允许安装来自浏览器的 APK。

Linux 0.2.4 为 Beta 测试版，需要 x86_64、glibc 2.34 或更新版本和 WebKitGTK 4.1。使用 apt 或 dnf 安装可自动解析依赖；动画、字体切换与高刷新率表现仍需在实际桌面环境中验证。
