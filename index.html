FocusFeed 是一款本地优先的 RSS 阅读器。订阅、阅读、整理与理解，在一个安静的空间里自然发生。

01 / READ

好内容，
值得好好读。

从 RSS 订阅到沉浸阅读，FocusFeed 把信息从纷杂的入口带回文章本身。

01—A

文章与电子书，
同一种专注。

在宽屏上展开双页阅读，留出恰到好处的文字空间。

  • 双页、翻页与滚动阅读，按你的习惯选择。
  • 字号、行距和阅读宽度都可调整。
  • 文章与电子书分开整理，使用同一套阅读工具。
01—B

留下值得
再读的一句。

高亮与批注就在文章旁边。读完后，把保存的摘录和想法导出，留作自己的阅读笔记。

  • 用高亮、直线或波浪线，区分不同的阅读标记。
  • 批注跟随选中文字保存，重读时能回到上下文。
  • 阅读页导出本篇笔记；设置 → 导出可批量选择全部或仅收藏的文章与书本章节。
  • 支持 Markdown / HTML；批量打包为 ZIP，保留原文链接、摘录、批注、颜色与时间。
01—C

小更新，
留在本机。

界面与已有功能的交互，可以下载小更新。阅读数据仍保存在设备上，断网也能继续阅读本地内容。

  • 设置 → 关于 → 界面小更新：主动检查、下载，也能导入更新包；下次启动生效。
  • 支持关闭、取消待更新包和恢复上一界面；新界面启动未确认时自动回退。
  • 设置 → Pro：复制授权码或导入、导出个人许可证文件，在自己的设备间携带，无需账号或设备码。
  • 更新检查不上传订阅、文章、授权码或 API 密钥。核心功能和系统能力的更新仍通过安装包提供。

02 / UNDERSTAND

让 AI 帮你理解，
由你决定怎么读。

摘要、翻译、解读与朗读，出现在阅读需要它们的地方。

自己的 API添加你使用的 AI 服务，为摘要、翻译等功能选择模型。保留服务商要求的 API 路径，也可填写完整接口地址；连接错误可查看和复制。

听文章为朗读单独选择语音模型，听当前文章、章节或选中文字。

本地优先订阅与阅读记录保存在设备上；已保存的 API 密钥由本地核心管理，设置页显示是否已保存。AI 请求发往你配置的服务。

清楚掌控第三方模型费用由对应服务商收取，FocusFeed 不提供托管额度。

在终端安装。

复制这条命令，自动选择 DEB / RPM、校验 SHA-256 并安装 Linux 0.2.0 Beta。支持 Linux Mint、Ubuntu、Debian（apt）与 Fedora（dnf）。

curl -fsSL https://focusfeed-site.pages.dev/install.sh | sh

安装前请关闭 FocusFeed。脚本会处理旧 Beta 重装与误标版本降级；仅安装阶段需要 sudo。需要 curl、sha256sum 和可提供 WebKitGTK 4.1 的软件源。

查看手动安装命令

Linux Mint / Ubuntu / Debian

curl -fL --proto '=https' --proto-redir '=https' 'https://focusfeed-site.pages.dev/download/FocusFeed_0.2.0_amd64.deb?rev=82f8213eaa4adb8371878513d140d5c56b5611ef3a3ce99f9d9c7a4573518e3c' -o 'FocusFeed_0.2.0_amd64.deb' &&
printf '%s  %s\n' '82f8213eaa4adb8371878513d140d5c56b5611ef3a3ce99f9d9c7a4573518e3c' 'FocusFeed_0.2.0_amd64.deb' | sha256sum -c - &&
sudo apt-get install --yes --allow-downgrades --reinstall './FocusFeed_0.2.0_amd64.deb'

Fedora（dnf）

curl -fL --proto '=https' --proto-redir '=https' 'https://focusfeed-site.pages.dev/download/FocusFeed-0.2.0-1.x86_64.rpm?rev=d80fea45684aadad8a192bb67a5f7f982e1c4e90d5a23b7626f9619787ec7778' -o 'FocusFeed-0.2.0-1.x86_64.rpm' &&
printf '%s  %s\n' 'd80fea45684aadad8a192bb67a5f7f982e1c4e90d5a23b7626f9619787ec7778' 'FocusFeed-0.2.0-1.x86_64.rpm' | sha256sum -c - &&
sudo dnf install './FocusFeed-0.2.0-1.x86_64.rpm'

RPM 已安装同版时，将 install 改为 reinstall；误标的 0.17.0 需改为 downgrade。安装后从应用菜单启动，或以普通用户运行 rss-cross-app。

查看安装脚本 ↗

Windows 文件暂未进行代码签名，系统可能显示“未知发布者”；安装前可核对上方 SHA-256。Android 版需要 ARM64 设备，并允许安装来自浏览器的 APK。

Linux 0.2.0 为 Beta 测试版，需要 x86_64、glibc 2.34 或更新版本和 WebKitGTK 4.1。使用 apt 或 dnf 安装可自动解析依赖；动画、字体切换与高刷新率表现仍需在实际桌面环境中验证。
